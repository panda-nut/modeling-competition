# 数据管理

## 目录

| 路径 | 内容 | 修改规则 |
| --- | --- | --- |
| `raw/` | 题目官方原始数据 | 只读，不改名、不覆盖 |
| `processed/q1/`—`processed/q5/` | 各问可重建的处理与模型输出 CSV | 只能由登记程序生成 |
| `processed/validation/` | 独立验证使用的 CSV | 必须记录验证程序和口径 |

数据定位见 `data-index.md`。作图程序必须读取这里已经保存的 CSV，不得依赖未落盘的内存结果。

处理文件登记至少包含：来源、程序、命令、行列数、字段、单位、场景、随机种子、SHA-256、技术阶段和 Evidence ID。当前迁移进来的 CSV 不自动视为已冻结。
