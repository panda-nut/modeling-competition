# 程序索引

程序按问题组织，每问再分为：

| 次级目录 | 用途 |
| --- | --- |
| `model/` | 数据准备、模型拟合、优化和机器可读结果输出 |
| `validation/` | 独立复现、约束、泄漏、误差、收敛和边界检查 |
| `plotting/` | 只读取 `03_data/processed/` 的 CSV/JSON 并生成 `05_figures/` |

公共路径、随机种子、绘图样式和验证工具位于 `common/`。详细文件定位见 `code-index.md`。

现有正式绘图入口已从处理数据 CSV 生成工作图。部分迁移模型脚本内部仍保留未调用的
历史绘图辅助函数，后续重构时可以删除；主入口不得重新直接产出正式图。
